## 2. 阶段规划对比表（短期 · 中期 · 长期）

| 维度 | 短期目标 (Short-term · 1~2周) | 中期目标 (Mid-term · 1~2月) | 长期愿景 (Long-term · 6月+) |
| :--- | :--- | :--- | :--- |
| **产品形态** | 个人极简高保真精听神器 | 具备自适应能力的智能学习系统 | 全自主 AI 语言管家与影视交互生态 |
| **精听体验** | 单句循环、0.75x~1.25x 变速、双语/单语自适应切换 | 影视级波形微调、盲听高频错题重听清单 | 真实对话影子跟读测评、发音音变纠错 |
| **AI 介入度** | 随堂 3 题快测、AI 伴学抽屉答疑、首页动态卡片 | 纯英文 Anki 连读/弱读自动标注、智能错题聚类 | 动态调控全 App 界面组件、生成自适应课程 |
| **记忆体系** | 纯英文生词打星收藏、本地弱点表持久化 | 一键导出标准 `.apkg` 卡包、原声切片挖空复习 | Anki Web 双向同步、艾宾浩斯智能排程 |
| **教材支持** | 《你的名字》电影全片 (1589 句)、TED-Ed 原版 | 批量解析 YouTube / B站高质量演讲与影视 | 3 小时超长视频全自动一键转精听教材 |
