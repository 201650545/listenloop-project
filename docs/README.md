# ListenLoop 商业工程知识库 (Project Repository)

> **ListenLoop** 是一款面向严肃外语学习者的 **AI 智能管家驱动的影视级逐句精听与抗遗忘学习系统（Learning Runtime）**。
> 本仓库遵循商业工程级知识管理标准组织，提供面向用户的**可视化驾驶舱**与面向 AI 的**机器检索通道**。
