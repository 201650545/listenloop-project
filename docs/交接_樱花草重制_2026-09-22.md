## 五、坑位备忘（本会话实测）

1. **whisper.load_model("medium") 在本机必炸**：Loomy shell 到 azure CDN 的大文件传输被网关损坏，报 `SHA256 checksum does not not match`。**解法：传本地 checkpoint 路径** `whisper.load_model(r"D:\...\medium.pt")`（走 isfile 分支不下载）。medium.pt sha256=`345ae4da62f9b3d59415adc60127b97c714f32e89e936602e85993674d08dcb1` ✓
2. **手机浏览器下载的 medium.pt 曾截断**（1,528,008,539 vs 官方 1,533,441,383 字节），拉回后务必 `Get-FileHash` 校验。
3. **中文歌转写必须 web 校对**：medium 对唱词仍有系统性同音误转，成稿前以官方歌词逐句比对。
4. **写库前必须装 debug 包**：run-as 仅 debug 可用；完成后装回 release。
5. **Loomy shell 的 HOME/USERPROFILE 重定向**：跑 python 前指回 `C:\Users\郭永涛`，whisper 缓存在 `C:\Users\郭永涛\.cache\whisper\`。
6. 设备意外断连时：`adb kill-server && adb start-server` 重握手即可。
7. `.nomedia` 隐形目录：`/sdcard/Android/data/com.listenloop.listenloop/` 打洞法 `adb push .nomedia /sdcard/Download/`。
