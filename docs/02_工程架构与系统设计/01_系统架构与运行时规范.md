# 01 系统架构与运行时规范 (System Architecture & Runtime Spec)

> [!NOTE]
> 本文定义 ListenLoop 的工程技术底座：**Learning Runtime（学习运行时）架构模式**，以及组件注册表与动态插槽规范。

---

## 一、 核心架构模式：Learning Runtime

```
┌─────────────────────────────────────────────────────────────┐
│                      Learning Runtime                       │
├─────────────────────────────────────────────────────────────┤
│  [Dynamic Slot: 首页弱点推荐]  [Dynamic Slot: 伴学解析抽屉]   │
│  [Component: 尚雯婕3分钟快测]  [Component: 纯英文Anki卡]      │
├─────────────────────────────────────────────────────────────┤
│                    Sentence Timeline Core                   │
│         毫秒级时间轴 · 媒体无损播放 · 多语种字幕渲染          │
├─────────────────────────────────────────────────────────────┤
│                 Storage & Native Driver Layer               │
│       SQLite 关系持久化 · just_audio ExoPlayer 驱动 · 本地沙箱 │
└─────────────────────────────────────────────────────────────┘
```

1. **Sentence Timeline Core（句子时间轴核心）**：
   - 绝不物理切割音频文件！完整保存原始 1~3 小时媒体文件（`.m4a` / `.mp4`）；
   - 句子只记录毫秒级起止范围（`startMs` ➔ `endMs`）；
   - 无论是本地离线音频播放，还是线上 Bilibili / YouTube 播放，共用同一套时间轴数据。

2. **Dynamic Slot & Component Registry（动态插槽与组件化）**：
   - **动态插槽（Dynamic Slots）**：在页面骨架中预留插槽位（如首页顶部 `_DynamicAiGovernorCard`、播放页顶栏 `✨` 入口）；
   - **组件注册表（Component Registry）**：AI 管家根据学习状态（例如存在未复习错题、刚完成一小节学习）动态激活不同组件填充插槽。

## 二、 SQLite 数据表设计契约 (Schema Contract)

1. **`lessons`（课程主表）**：
   - `id`: TEXT PRIMARY KEY
   - `title`: TEXT NOT NULL
   - `language`: TEXT NOT NULL (ISO/BCP-47: 'en', 'ja', 'zh')
   - `duration_ms`: INTEGER NOT NULL
   - `sentence_count`: INTEGER NOT NULL
   - `audio_path`: TEXT NOT NULL
   - `cover_path`: TEXT
   - `video_json`: TEXT (可选 Bilibili/YouTube 视频关联)
   - `imported_at`: TEXT NOT NULL

2. **`sentences`（句子时间轴表）**：
   - `lesson_id`: TEXT NOT NULL
   - `idx`: INTEGER NOT NULL (0..n-1 严格递增)
   - `sentence_id`: TEXT NOT NULL
   - `start_ms`: INTEGER NOT NULL
   - `end_ms`: INTEGER NOT NULL
   - `english`: TEXT NOT NULL (源语言台词文本)
   - `chinese`: TEXT NOT NULL (中文字幕翻译)
   - PRIMARY KEY (lesson_id, idx)

3. **`weakness_records`（弱点错题表）**：
   - `id`: TEXT PRIMARY KEY
   - `lesson_id`: TEXT NOT NULL
   - `sentence_index`: INTEGER NOT NULL
   - `question`: TEXT NOT NULL
   - `wrong_answer`: TEXT NOT NULL
   - `recorded_at`: TEXT NOT NULL
   - `resolved`: INTEGER NOT NULL DEFAULT 0
