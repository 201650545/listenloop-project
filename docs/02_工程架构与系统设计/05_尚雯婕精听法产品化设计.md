# 05 尚雯婕精听法产品化设计 (Shang Wenjie Method → Product)

> [!IMPORTANT]
> 本文回答两个问题：**这个方法到底是什么**（查证结果，非推测），以及**它在我们软件里应该怎么长出来**。所有方法描述均有多来源交叉印证，来源见文末。

---

## 一、 方法本体（查证结果）

### 1. 四步法（一个周期 = 一篇约 20 分钟的材料）

| 步骤 | 动作 | 关键细节（容易被漏掉的才是精髓） |
| :--- | :--- | :--- |
| **① 选材** | 找一段 20 分钟左右的新闻播报 / 访谈 / 演讲 / 播客 | 标准是**语法工整、逻辑清晰**，不是"内容简单"。**明确排除**：影视剧对话、文学作品、诗歌（语法太跳脱，不适合打基础）。基础弱可从 **3~5 分钟**素材过渡。且**必须是你真正感兴趣的内容** —— 大脑只对有情绪刺激的内容形成深度记忆 |
| **② 听写** | 逐字逐句写下来 | 先**通听 3~5 遍（甚至 10 遍）**建立上下文结构，再落笔；听不出来的**先空着**，不要暂停抠；写完全篇后再对照原文修改。功能是强迫大脑完成「声音识别 → 语音切割 → 语义匹配 → 拼写输出」的闭环，专治"看得懂但听不懂" |
| **③ 查证** | 查字典、抠语法 | 把整篇**每个单词、每个句子结构**都弄明白。不是只查生词 |
| **④ 背诵** | 整篇整段背下来 | **不是背单词、背句型，是背全文**。且**背诵速度必须与原音频同步** —— 这是全方法的**分水岭**：同速输出意味着大脑不再经过"中文→外语"转换，语言进入本能层 |

### 2. 周期与量

- **一篇 20 分钟材料 = 一个周期**，走完四步
- **做满 10 篇** → 这门语言达到可当工作语言使用的水平
- 尚雯婕本人：大一发现真实水平不足后退掉所有社团，每天有效学习 **15 小时**，4 个月法语突飞猛进，两年修完四年本科内容（复旦法语系，其师蔡槐鑫评价其同传水平在上海可排前五）

### 3. 无外语环境时的变体（她后来说的补充版）

没有语言环境时输出做不了，只剩输入，于是：

- **"高效听"**：每天 **30 分钟全神贯注地听**，放下手里所有事。**明确反对**边刷牙边听、边走路边听 —— 那是"低效听"，脑子根本没进去
- **专注读**：每天 30 分钟读新闻稿、说明文，甚至**儿童读物**（语法规整、不复杂）
- 心智模型：人脑像数据库，输入足够丰富就能**以量维持质**，最终溢出到输出

### 4. 一句话总结原理

> 通过高强度的**听觉输入**（听写）与**强制输出**（同速背诵），绕过低效路径，直接在脑中重建一套听觉反射系统。

## 二、 现状对照：我们现在差在哪

> [!WARNING]
> **现有功能名不副实**：App 里那张「尚雯婕 3 分钟限时精听法」卡片，实际内容是**3 道选择题的快测**（`generateQuizQuestions` 生成听力理解／连读辨音／语境语感三题）。这与尚雯婕方法**没有任何关系** —— 我们没有用她的方法，只是用了她的名字。这一点必须先承认。

| 方法步骤 | App 现状 | 缺口 |
| :--- | :--- | :--- |
| ① 选材 | 课程库 + 链接制课（B站/YouTube/本地文件） | 无"素材语法工整度"提示；无"20 分钟/10 篇"的周期概念 |
| ② **听写** | **完全没有** | **最大缺口。听写是这套方法的灵魂** |
| ③ 查证 | 有逐句中英对照、AI 可解析语法 | 无"我到底漏了哪些词、为什么漏"的诊断 |
| ④ **同速背诵** | **完全没有** | 无录音、无跟读、无同速判定 |
| 周期追踪 | 有学习进度（第几句） | 无"训练周期"维度，只有"播放进度"维度 |

## 三、 产品化设计

### 3.1 主结构：一篇 = 一个训练周期（四阶段流水线）

在现有精听页之上，新增**训练模式**，把四步做成可推进的状态机：

```
① 盲听预习  →  ② 听写  →  ③ 查证  →  ④ 同速背诵  →  周期完成
```

每阶段有**可量化的完成判据**（否则无法"复刻"方法）：

| 阶段 | 完成判据 |
| :--- | :--- |
| ① 盲听预习 | 全篇通听 ≥ 3 遍（App 计数，不看字幕） |
| ② 听写 | 逐句听写提交率 100%（每句至少提交一次） |
| ③ 查证 | 所有"未识别词"标记为已查（一键标记 + 自动反查） |
| ④ 同速背诵 | 每句 ASR 相似度 ≥ 90% **且** 时长比 ∈ [0.9, 1.1] |

> 判据全部本地可算，不依赖 AI，不会因为额度/网络失败而卡住流程。

### 3.2 听写模式（需新建，核心功能）

- **两种粒度**：逐句听写（默认，压力小）／整段听写（进阶，还原方法原貌）
- **播放**：可 0.75× 慢速、可循环 N 次、可回退 3 秒
- **防作弊**：听写提交前**锁定字幕**（这是方法的关键 —— 先硬听，再看原文）
- **批改**：提交后做**词级 diff**（LCS 对齐），三色标注
  - 漏词（红）／多写（黄）／拼写近似错（橙）
- **可解释反馈**：漏掉的词如果是功能词（to/for/of/and），提示"这是弱读吞音，属于必然难点"；如果是实词，提示"这是关键词，需要回到原声再听"
  - 这一步把"听写"从机械劳动变成**有针对性的训练**，也是我们相对纸笔听写的唯一优势

### 3.3 同速背诵模式（需新建）

- 提示分级（按难度递进）：中文译文 → 首字母 → 关键词 → 无提示
- 录音 → ASR 转写 → 与原句做相似度比对
- **时长比对**：`录音时长 / 原声时长` 落在 [0.9, 1.1] 判定"同速达成"
- **双指标反馈**：准确度（对没对）+ 速度（快没快）。只报准确度会让人慢慢念，恰恰违背方法的精髓

### 3.4 10 篇训练营（周期管理）

- 目标：走完 **10 篇**（每篇约 20 分钟素材）
- 首页进度环 + 每篇四阶段状态点
- 完成 10 篇给里程碑提示（按方法原话：可作工作语言）
- 允许自定义篇数（3 / 5 / 10），不要一上来就压 10 篇

### 3.5 关于那张旧卡片

| 现状 | 建议 |
| :--- | :--- |
| 「尚雯婕 3 分钟限时精听法」（3 道选择题） | ① 卡片**改名并指向新的四步流水线**（如「尚雯婕四步法 · 继续训练」）；② 3 道选择题**保留但改名**（如「3 分钟自测」）—— 它本身是合理的快速检测，只是不该打尚雯婕的旗号 |

## 四、 实现拆解（工单级）

| 阶段 | 内容 | 依赖 | 备注 |
| :--- | :--- | :--- | :--- |
| **P1** | 听写引擎：逐句盲听 + 输入 + LCS 词级 diff + 三色标注 | 纯本地，无 AI | 可独立交付，价值最大 |
| **P2** | 同速背诵：录音 + ASR 转写（MiMo `mimo-v2.5-asr`，实测 0.6s）+ 时长比判定 | P1 的 diff 逻辑可复用 | 需录音权限 |
| **P3** | 训练周期状态机 + 10 篇训练营 | P1、P2 | 数据落 SQLite |
| **P4** | 素材建议（语法工整度提示、时长筛选 3~20 分钟） | 无 | 可在课程库加标签 |

## 五、 取舍与风险

1. **这个方法本身很痛苦**（"最笨、最直接、也最扎实"）。产品不能把它包装成轻松速成，否则用户第一周就流失。建议提供**最小可行剂量**：默认 3~5 分钟素材起步，进度可见，允许中断续做。
2. **听写要不要允许慢速？** 原方法强调"反复听"，未禁止降速。建议允许 0.75×，但**记录使用率**，作为后续难度调节依据。
3. **中文提示的多少** —— 与我们"纯英文"的重心冲突。建议：正面纯英文，中文只在"查证"阶段作为对照出现，且可关闭。
4. **10 篇的素材从哪来** —— 我们已有的 B站/YouTube 制课能力正好覆盖"新闻/访谈/演讲/播客"，但需要给用户**选题建议**（避免选到影视剧）。

---

## 六、 需要拍板

1. 听写默认粒度：**逐句**（压力小）还是**整段**（还原原方法）？
2. 同速判定的阈值 **[0.9, 1.1]** 是否接受（即允许 ±10% 语速偏差）？
3. 那句 3 道选择题：**保留改名** 还是**直接删掉**？
4. 训练营默认篇数：3 / 5 / **10**？
