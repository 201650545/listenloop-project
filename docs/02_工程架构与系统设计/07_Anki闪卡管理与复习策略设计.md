# 07 Anki 闪卡：管理模块与复习策略设计 (Flashcard Management & Scheduling)

> 本文回答两个问题：**闪卡该放在哪里管**（现在是塞在 AI 抽屉的第三页），以及**复习/学习策略怎么定**（不能只有一个 SM-2 公式）。

---

## 一、 现状

| 项目 | 现状 | 问题 |
| :--- | :--- | :--- |
| 卡片数据 | `AnkiCard`：sentenceText / chineseTranslation / clozeWord / phoneticClue / aiExplanation / SM-2 字段（repetition、intervalDays、easeFactor、dueDate、isMastered） | 卡面三字段全由**本地中文模板**生成，AI 未参与；`clozeWord` 取"最后一个词"无语义重点（详见 04 文档） |
| 算法 | SM-2 完整实现（again/hard/good/easy → 间隔 `<10min / 1d / 3d / 7d`，ease 1.3~3.0，≥21d 判定掌握） | 算法没问题，**缺的是围绕它的产品层** |
| 入口 | 藏在「AI 智能管家」弹层的**第三个 tab** | 与"复习是一件需要专门空间的事"矛盾：复习时不该先打开一个聊天抽屉 |
| 管理 | 只有 Library 首页一张「今日精听弱点」卡 | 无卡片列表、无筛选、无统计、无批量操作 |
| 学习中心 | `AGENT_MANIFEST.json` 里 `L1_LEARN` = `NEXT_SPRINT` | 未实现 |

## 二、 管理模块：闪卡需要自己的位置

### 1. 放哪里：两个方案

| 方案 | 做法 | 优点 | 缺点 |
| :--- | :--- | :--- | :--- |
| **A. 新增 L1 tab「学习」** | 底部导航从 4 个变 5 个（课程/精听/学习/创建/设置） | 复习有独立入口，符合"每日必做"的心智；未来可容纳生词本、训练营进度 | 导航拥挤；精听与学习割裂 |
| **B. Library 内二级入口** | 课程页顶部一张「闪卡」卡，点进独立页面 | 导航不变；与课程库同源（卡片本来就来自课程） | 入口较深，容易忘 |

> [!TIP]
> **建议先做 B，再看是否升级到 A。** 理由：闪卡来源是课程（打星句、听写错句），放在课程页与来源同屏更自然；且新增 tab 是不可逆的产品结构改动，等复习习惯真正养成再升级。

### 2. 页面结构（闪卡管理页）

```
┌─ 闪卡 ──────────────────────────────┐
│ 今日到期 12      全库 147   连续 6 天 │   ← 三个指标
├─ 筛选 ──────────────────────────────┤
│ [全部] [连读] [弱读] [闪音] [失爆]    │   ← 按音变类型（对齐 03 文档四大音变）
│ [按课程 ▾]  [按掌握度 ▾]              │
├─ 卡片列表 ──────────────────────────┤
│ Pick it [ ___ ] up and put it...    │
│ 连读 · 来自《你的名字》 · 下次 3 天后  │
│                          [▶] [编辑]  │
│ ...                                 │
├─ 底部 ──────────────────────────────┤
│ [开始复习 12 张]        [导出 .apkg] │
└─────────────────────────────────────┘
```

要点：

- **来源可点**：每张卡标注来自哪课哪句，点击**跳回原片现场**（复用现有 `onPlaySnippet`）
- **音变类型是核心筛选维度** —— 这是我们相对通用 Anki 的独有优势：卡片带发音学标签
- **批量操作**：删除、重置进度、按课程清理
- **导出 `.apkg`**：契约已在 `03_纯英文Anki与AI机制设计.md` 第三节定义（含 media 映射与切片音频）

## 三、 复习策略（Scheduling）

### 1. 保留 SM-2，补齐产品参数

SM-2 已实现，缺的是 Anki 那套「每日上限 + 学习步骤」的控制：

| 参数 | 建议默认 | 理由 |
| :--- | :--- | :--- |
| 每日新卡上限 | **10** | 新卡是"学习"，复习是"维持"。新卡过量会挤掉复习 |
| 每日复习上限 | **100** | 防止积压日突然爆量导致放弃 |
| 学习步骤 | `<10min → 1d → 3d` | 现有实现已是这套，保持 |
| 毕业间隔 | 4d | 走出学习步骤后的首次正式间隔 |
| 简单加成 | ×1.3（已有） | 现有 SM-2 已含 |
| 掌握阈值 | ≥21d（已有 `isMastered`） | 与 Anki 惯例一致 |

### 2. 弱项优先（这是我们的差异化）

按 **音变类型** 统计错误率，形成「发音弱项雷达」：

```
连读  ██████░░░░  62%   ← 弱项，优先出卡
弱读  ████████░░  81%
闪音  █████████░  90%
失爆  █████░░░░░  51%   ← 最弱，优先出卡
```

- 每天复习队列按「错误率 × 到期权重」排序，弱项类型卡片**提前出现**
- 每周给一次"弱项变化"小结（哪类音变进步了）

> 这一步把闪卡从"通用记忆工具"变成"发音训练的诊断仪"，也是与 AnkiDroid 等成熟工具**正面竞争的唯一理由**。

### 3. 复习交互（对齐 03 文档的纯英文卡面）

- **正面**：音频 + 英文挖空句 + 英文发音提示 → 用户先**听**，再**回忆**
- **背面**：目标词 + 完整英文句 + 中文释义（唯一中文位）+ 英文音变拆解
- 四个评分按钮沿用 `again / hard / good / easy`，但**标签要换成实际间隔**（`<10分钟 / 1天 / 3天 / 7天`），比"生疏/困难/良好/轻松"更有决策信息

## 四、 学习策略（什么句子变成卡）

| 来源 | 触发时机 | 优先级 |
| :--- | :--- | :--- |
| 用户打星 | 精听页点星标 | 高（用户主观判定"这句重要"） |
| **听写错句** | 尚雯婕四步法②听写提交后，有漏词/错词的句子 | **最高**（客观证据表明没听懂） |
| 跟读失败句 | 四步法④同速背诵未达标（相似度 <90% 或语速偏差 >10%） | 高 |
| AI 判定 | 伴学对话中模型认为"该句含高频音变结构" | 中（需用户确认，不自动入卡） |

原则：**入卡必须有证据**（用户标记或客观测试失败），不做"AI 自动批量生成"—— 那只会制造一座用户永远不会复习的卡片坟场。

```
        ↓ 制卡
     闪卡库  ←→  听伴（拆音变时可直接入卡）

   复习会话  →  跳回原片现场（onPlaySnippet）

   .apkg（桌面 Anki / AnkiMobile / AnkiDroid 通用）
```
