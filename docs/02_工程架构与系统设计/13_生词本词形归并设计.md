# 13 生词本词形归并（Lemma）设计裁决稿

> 承接 [[10_生词本与Anki记忆卡设计]] §十六.6 的未做项「lemma 归并与 phrase lexicon」。
> 本篇只解决**词形归并**；phrase lexicon（词组库）另行立项（见 §五）。

## 一、问题定义

现状：生词本按 `surfaceForm` **精确判重** —— `walked` 和 `walk` 是两个词条、`went` 和 `go` 是两个词条、`children` 和 `child` 是两个词条。

后果（按严重度排）：

1. **SRS 进度分裂**：同一个词两张卡各排各的复习节奏 —— 直接违背 10 号派生规则 3「一个词一张卡，掌握度能累积」的立库之本；
2. **今日计划重复出组件**：听写漏了 `walked`、又点存了 `walk` → 同一个能力点练两遍；
3. **弱项信号稀释**：07 号弱项优先的错误统计被词形分摊，雷达不准。

## 二、核心裁决：导入时归并 vs 展示时聚合

| | 方案 A · 导入时归并 | 方案 B · 展示时聚合 |
|---|---|---|
| 做法 | 新 occurrence 进来先还原 lemma，挂到 lemma 词条 | 存储不动，聚合视图按 lemma 分组 |
| SRS 聚合 | ✅ 天然一张卡 | ❌ 仍分裂（各排各的） |
| 存量数据 | **必须一次性迁移**（保守合并） | 零迁移 |
| 复杂度 | 集中在还原器 + 一次迁移 | 聚合规则散落在计划/队列/弱项三处 |
| 回滚 | 迁移前快照兜底 | 无需 |

**推荐方案 A**。理由：B 方案让「一个词一张卡」在词形维度永远失效，聚合规则要抄进三处调用方（计划引擎、复习队列、弱项统计），漏一处就出双卡 —— 长期成本高于一次可控迁移。A 的风险集中在「还原错了」，由 §三 的保守策略 + occurrence 保留原始词形兜底。

## 三、lemma 还原器（端侧 · 离线 · 零新依赖）

三层结构，**逐层兜底，不做猜测**：

| 层 | 覆盖 | 例 |
|---|---|---|
| 1 · 不规则词表 | 内置 ~180 个高频不规则动词/名词复数/比较级（常量 Map，可后续扩充） | went→go、children→child、better→good、mice→mouse |
| 2 · 规则词尾剥离 | -s/-es/-ed/-d/-ing + 双写辅音还原 + -ied→-y | walks→walk、stopped→stop、running→run、studied→study |
| 3 · 兜底 | 还原失败 = 自身 | 专有名词、未登录词、缩写不猜 |

**显式不做**：

- ❌ 端侧小模型做 lemma —— sherpa_onnx 是 ASR 用途，用模型做词形还原是大炮打蚊子且引入不确定输出；
- ❌ 联网查词典 —— 离线红线（§5.5 同源纪律）；
- ❌ 一切"疑似还原"：层 2 剥完若与任何已知形态规则冲突，宁可保持原形。

**误还原兜底**：lemma 只用于**判重与归并**；`VocabularyOccurrence` 永远同时保留 `surfaceForm`（原始词形，进句子定位用）与 `lemma`（归并键）。还原规则日后升级时，可凭原始词形**全量重算**，不需要用户重新听写。

## 四、数据模型变更与迁移

1. `VocabularyOccurrence` 加字段 `lemma`（`String?`，JSON 向后兼容：旧档 null = 按 surfaceForm 小写兜底）；
2. `VocabularyStore` 判重键：`surfaceForm` → `lemma ?? surfaceForm`（小写化）；
3. **一次性迁移**（启动时执行，带 `v2_lemma_merged` 标记防重跑）：
   - 按 归并键 分组，同组多卡 → 保留 `createdAt` 最早者为主卡；
   - `occurrences` / `drills` **全部并入**主卡（不丢任何证据）；
   - `status` 取组内最高进度（known > learning > candidate；ignored 独立保留）；
   - `srs` 保留 `reps + lapses` 更大的一张（进度多的赢），另一张丢弃但 occurrence 证据不丢；
4. **迁移前快照**：整个 vocabulary store JSON 写入本地备份文件（`vocab_backup_pre_lemma.json`），出问题可整包恢复。

## 五、与 phrase lexicon 的关系

`kind == phrase` 的词条**不参与归并** —— "give up" 归到 "give" 是错误归并。归并只在 `kind == word` 内进行。phrase lexicon（跨课词组库、短语卡片）独立立项，本轮不做。

## 六、工作量与验收

- **实现 ~1 天**：还原器纯函数（表驱动测试覆盖三层）+ 迁移逻辑 + 迁移快照；UI 零变化；
- **验收标准**：
  1. 构造 went/walked/running 三个词形的证据 → 归并后一张卡、seenCount 累计 3；
  2. 迁移后 drills / occurrences 逐条还在（测试断言不丢）；
  3. phrase 词条不受影响；
  4. 迁移快照文件生成且可读；
  5. 全量测试绿 + 小米 14 真机回归。

## 七、待拍板（郭老师勾选）

1. **方案**：A 导入时归并（推荐）/ B 展示时聚合
2. **不规则词表规模**：~180 高频起步（推荐）/ 一次性上全量 370+（引用 MIT 词表，包体 +~8KB）
3. **迁移时机**：下个版本启动时自动 + 快照兜底（推荐）/ 等生词本存量过百再迁
4. **还原失败的词**：保持独立卡（推荐，不做猜测）
